# 📊 Exploratory Data Analysis - Project 1

This project focuses on performing Exploratory Data Analysis (EDA) on a dataset using Python. The goal is to understand the data, identify patterns, detect anomalies, and extract meaningful insights using statistical and visualization techniques.

---

## 🔍 Key Steps in EDA

### 1️⃣ Data Understanding
- Checking dataset shape, columns, and data types  
- Summary statistics (mean, median, etc.)  

### 2️⃣ Data Cleaning
- Handling missing values  
- Removing duplicates  
- Fixing inconsistent data  

### 3️⃣ Data Analysis
- Univariate analysis (single variable)  
- Bivariate analysis (relationship between variables)  

### 4️⃣ Data Visualization
- Histograms  
- Box plots  
- Scatter plots  
- Heatmaps  

EDA helps uncover hidden patterns, relationships, and anomalies in the data. :contentReference[oaicite:1]{index=1}
